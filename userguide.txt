  1.  GETTING STARTED
==================================================================

  1. Compile and run the program (see requirement.txt).
  2. The title appears, followed by the Main Menu:

        +----------------------------------+
        |   1.  Customer Portal            |
        |   2.  Admin Portal               |
        |   3.  Exit                       |
        +----------------------------------+

  3. Type the number of your choice and press ENTER.

  TIPS
  ------------------------------------------------------------
     [i]  Enter menu choices as numbers only.
     [i]  Answer Yes/No questions with Y or N.
     [!]  Admins must always use "Save/Exit" (Admin Menu,
          option 6) when finished so that data is saved.


==================================================================
  2.  CUSTOMER PORTAL            (Main Menu -> 1)
==================================================================

        +----------------------------------+
        |   1.  Login                      |
        |   2.  Register                   |
        |   3.  Back                       |
        +----------------------------------+

  2.1  Register a New Customer
  ------------------------------------------------------------
     Step 1   Choose 2 (Register).
     Step 2   Enter Name            (must be unique).
     Step 3   Enter Phone Number.
     Step 4   Enter Email           (must be unique; it becomes
                                     your USERNAME).
     Step 5   Select a Password.
     Step 6   You return to the Customer Menu and your data
              is saved.

     [!] If the name or email already exists, registration
         restarts.
     [!] A maximum of 10 customers can be registered.

  2.2  Login
  ------------------------------------------------------------
     Step 1   Choose 1 (Login).
     Step 2   Enter your username (your email) and password.
     Step 3   "Access Granted" displays your dashboard:
                - Username
                - Name
                - Phone number
                - Email
                - Rental status
     Step 4   If you have rented a vehicle, the vehicle
              details, number of days and amount owed (Rs.)
              are also shown.

     "Access Denied" means the username or password is wrong.

     [i] Customers can only VIEW their information. Renting
         and returning vehicles is done by the Admin.


==================================================================
  3.  ADMIN PORTAL               (Main Menu -> 2)
==================================================================

  Login Credentials
  ------------------------------------------------------------
     Username :  admin
     Password :  admin123

  Admin Menu
  ------------------------------------------------------------
        +----------------------------------+
        |   1.  Customer Management        |
        |   2.  Vehicle Management         |
        |   3.  Rent Vehicle               |
        |   4.  Return Vehicle             |
        |   5.  Transaction Details        |
        |   6.  Save/Exit                  |
        +----------------------------------+

  3.1  Customer Management            (Admin Menu -> 1)
  ------------------------------------------------------------
     1.  Customer Details       Lists all customers.
     2.  Customer Registration  Adds a customer (same steps
                                as Section 2.1).
     3.  Search Customer        Finds a customer by email.
     4.  Back                   Returns to the Admin Menu.

  3.2  Vehicle Management             (Admin Menu -> 2)
  ------------------------------------------------------------
     1.  Vehicle Details        Lists all vehicles + status.
     2.  Vehicle Registration   Adds a vehicle:
                                  - ID is auto-generated
                                    (VEH-1, VEH-2, ...)
                                  - Enter vehicle name
                                  - Enter identification
                                    number (must be unique)
                                  - Enter daily rent
                                    (numbers only)
     3.  View Available Vehicles
     4.  View Rented Vehicles
     5.  Search Vehicle         Search by Vehicle ID.
     6.  Back

     [!] A maximum of 10 vehicles can be registered.

  3.3  Rent Vehicle                   (Admin Menu -> 3)
  ------------------------------------------------------------
     Step 1   The list of available vehicles is displayed.
     Step 2   Enter the Customer Name. The customer must
              exist and must not already be renting.
     Step 3   Enter the Vehicle ID of an available vehicle.
     Step 4   Confirm with Y to rent (N cancels).
     Step 5   Enter the number of days.
     Step 6   The system shows the vehicle details, number of
              days and the total owed:

                  TOTAL OWED  =  Daily Rent  x  Days

  3.4  Return Vehicle                 (Admin Menu -> 4)
  ------------------------------------------------------------
     Step 1   Enter the Vehicle ID.
     Step 2   If the vehicle is rented, the amount owed is
              shown.
     Step 3   Confirm the return with Y.
     Step 4   Choose Y to pay, then enter the EXACT amount.

              +-----------------+--------------------------+
              | Amount entered  | Result                   |
              +-----------------+--------------------------+
              | Correct         | Payment accepted,        |
              |                 | revenue increases,       |
              |                 | vehicle and customer     |
              |                 | become free              |
              | Incorrect       | "Incorrect Amount",      |
              |                 | rental stays active      |
              +-----------------+--------------------------+

     Choosing N at any confirmation leaves the vehicle rented.

  3.5  Transaction Details            (Admin Menu -> 5)
  ------------------------------------------------------------
     Displays the total Business Revenue collected so far.

  3.6  Save/Exit                      (Admin Menu -> 6)
  ------------------------------------------------------------
     Saves customers, vehicles and revenue to files and
     returns to the Main Menu. Choose 3 (Exit) in the Main
     Menu to close the program.

==================================================================
  5.  TYPICAL WORKFLOW EXAMPLE
==================================================================

     1.  Admin Portal  -> log in -> Vehicle Management
                       -> register vehicles.
     2.  Customer Portal -> Register
                       (or the Admin registers the customer).
     3.  Admin Portal  -> Rent Vehicle
                       -> choose customer, vehicle and days.
     4.  Customer Portal -> Login
                       -> view rental status and amount owed.
     5.  Admin Portal  -> Return Vehicle
                       -> pay the exact amount.
     6.  Admin Portal  -> Transaction Details
                       -> view revenue.
     7.  Admin Portal  -> Save/Exit, then Main Menu -> Exit.


==================================================================
  6.  TROUBLESHOOTING
==================================================================

  Problem :  "Access Denied"
  Fix     :  Check the username (email) and password spelling
             and letter case.

  ------------------------------------------------------------
  Problem :  "Customer Not Found" while renting
  Fix     :  The name must match exactly, and the customer
             must not already have a rented vehicle.

  ------------------------------------------------------------
  Problem :  "Incorrect Amount"
  Fix     :  Enter exactly the amount shown after "You Owe".

  ------------------------------------------------------------
  Problem :  Program loops endlessly after typing a letter
             at a menu
  Fix     :  Press Ctrl+C, restart, and enter numbers only.

  ------------------------------------------------------------
  Problem :  Data missing after restart
  Fix     :  Data is saved only through Save/Exit (or customer
             self-registration). Always use Save/Exit.

  ------------------------------------------------------------
  Problem :  "Maximum Number Of Customers/Vehicles Registered"
  Fix     :  The system supports up to 10 of each.
